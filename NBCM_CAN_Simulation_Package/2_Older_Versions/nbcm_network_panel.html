قطع گره (Node Timeout)
این پنل یک شبیه‌سازی محلی و بصری از سناریوی CAPL قبلی‌ست (بدون اتصال واقعی به CANoe/VN1640A) — برای کنترل واقعی NBCM روی باس، همین چیدمان و کلیدها را در Panel Designer بسازید و هرکدام را به یک System Variable متصل کنید که CAPL همان متغیر را می‌خواند (مثلاً سوئیچ «تزریق خطا» → سیستم‌ویر NBCM_Test::Abs::SpeedInvalid → در CAPL: msgAbsInfo2.Hs_Abs_VehicleSpeed_Invalid = @sysvar::NBCM_Test::Abs::SpeedInvalid; اگر بخواید، نسخه‌ی به‌روزشده‌ی فایل .can با همین سیستم‌ویرها رو هم براتون آماده می‌کنم.
